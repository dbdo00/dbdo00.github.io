SQL

I never wrote a line of sql in my programming. Neither have I ever learned it. Need get an item in a table? Just use dict in python. I always let Chatgpt write this query in native python, perhaps because the syntax of dict operation just feels tedious.

One top of this reason, using dict is not designed to store states. Is a thing changed or not? To do this, you need certain sort of hashing. How to implement? In the end of day, you naturally wonder if it is better to use a SQL.

Also, SQL is declarative. This means it is shorter and clearer when describing data. I have edited the code of and used the Python program rss2masto from github. It contains several pieces of SQL codes that share the common character of conccicence. I spent a day making some tweaks here and there to make it fit my needs better, but didn’t change anywhere the sql is used. It is good. It knows exactly which feeds are sent and which are not. I am motivated to learn SQL now.
