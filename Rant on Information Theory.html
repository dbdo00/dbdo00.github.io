First coding problems are discussed. (error and decoding) A question is how well we can do in decoding?

There is a probability for errors to occur, i.e. the digit 1 becomes 0, the digit 0 becomes 1, 1->0 , 0->1, in each digit of a binary sequence. You want to “decode” the digit that contains error(s), i.e. find the original digit with no or at least less errors.

Repetition Code

Example

Suppose you have the source message

s =  0 0  1 0  1  1 0

We add the noise to the source message in modulo 22 arithmetic. The result is the received message.

For every coordinates in the received message, the repetition code of the source code of that coordinate is either 000 or 111. We will make an educated guess whether the repetition code is 000 or 111.

We can compute this ratio of probabilities below P(𝐫|s=1)P(𝐫|s=0)\frac{P(\mathbf{ r } | s = 1) }{ P(\mathbf{ r } | s = 0 )}

If P(𝐫|s=1)P(𝐫|s=0)>0\frac{P(\mathbf{ r } | s = 1) }{ P(\mathbf{ r } | s = 0 )} > 0, then s=1s = 1 is more probale. Otherwise, it is the opposite case, i.e. s=0s = 0 is more probable.

So, we can make a table of most probable source message for each of 3 digit strings made up with 0 and 1s.
