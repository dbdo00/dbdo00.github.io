Proof That There is No Injection From Real Numbers to Natural Numberss



2025-11-11 For the sake of contradiction, we supppose the existence of an injection from reals to natural numbers.

If there is an injection from set A to set B, then there is a surjection from set B to set A.

Thus our assumption implies the existence of a surjection from natural numbers to reals.

This constructs a sequence of real numbers {x_n}. The point is that {x1,…,xn}\{x_1, \ldots, x_n\} is a finite set. So we can find an interval that “avoids” the first n terms of {xn}\{x_n\}. We construct the sequence {an},{bn}\{a_n\}, \{b_n\}, so that an≤an+1≤bn+1≤bna_n \leq a_{n+1} \leq b_{n+1} \leq b_n, bn+1−an+1≤1n+1b_{n+1} -a_{n+1} \leq \frac{1}{n+1} and xn∉[an+1,bn+1]x_n \not\in [a_{n+1}, b_{n+1}]. So there is a nested interval in which the n-th interval avoids the first nn terms of {x_n}. Hence the intersection of all of them avoids all xnx_n. This means avoiding all real numbers. This is impossible for non-empty subsets of real number. Contradiction!
