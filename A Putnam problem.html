A Putnam problem

Alice and Bob take turns to take numbers from an array

{1, 2, ..., n}

Bob wins if the goal that is decalred before the game is achieved when the game ends. Otherwise Alice wins the game.

If the array length is odd, then the winning stategy exists. k = 0 can be achieved by Bob with no barriers.

The difficult situation is when the array length is even.

The following is a strategy for Bob to achieve k=0k=0 in any situations when the array is even and is greater than 2.

  1. In the first round, if Alice chose n, the Bob chooses whatever that is not 2. If Alince didn’t choose n, then Bob needs to choose n.
  2. In the rest of the game, Bob chooses any number other than k in each k-th turn.
  3. Finally, Bob chooses any number other than n in the n-th turn. Alice cannot stop Bob from doing so because n is already chosen in the first or the second turn (by Alice or by Bob respectively).
