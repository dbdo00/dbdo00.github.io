q value in bandit

q is the expect reward after once greedy action, followed by optimal policy after this first action. q is where you get the reward. bandit does not compute q explictly, and instead it updates the self.value to each chosen_arm using the weighted sum of previous value and the reward (this is the immediate reward).

What is the connection between q value and the self.value that is updated?

To make it clearn, there is no “future” accumulative reward as in Q-learning (hence every reward is immediate) in bandit. So, q as in the definition of q(a,s)q(a,s) in Q-learning does not make sence for a mutli-arm bandit.
