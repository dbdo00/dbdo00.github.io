Regret = $\rm \left( What\ I\ could\ (have\ expected\ to)\ have\ gained\ I\ knew\ \\ what\ is\ best \right)-$ $\rm what\ I\ have\ gained$

Example. $q(1)\sim \rm {Bern}(0.1),\ q(2)\sim \rm {Bern}(0.5),\ q(3)\sim \rm {Bern}(0.6)$.
However, I do not know the value (i.e. the reward). I acted $1,\ 2,\ 3$ sequentially.
As a result, the expected value of my reward is

$$\mathbb E {\left[q(1) + q(2) + q(3)\right]} = \mathbb E\left[q(1)\right] + \mathbb E[q(2)] + \mathbb E[q(3)]= 0.1 + 0.5 + 0.6 = 1.2$$

The expected value of reward of taking the action $3$ sequentially for $3$ times is
$$\mathbb E[q(3) + q(3) + q(3)] = 1.8$$

So my regret is
$$1.8 - 1.2 = 0.6.$$

Contexual Bandit

States $\{s_1, s_2\}$.
Action $\{a_1, a_2\}$.

$$\phi(s_i, a_j) = (v_{1i},\ v_{2j})^\top$$
$$\phi(s_i, a_j) \begin{pmatrix} \theta_1 \\ \theta_2 \end{pmatrix} = v_1i \theta_1 + v_2j \theta_2$$

We want to solve (with minimal error) for $\theta_1, \theta_2$ in
$q(s,a) = \phi(s_i, a_j) \begin{pmatrix} \theta_1 \\ \theta_2 \end{pmatrix} = v_1i \theta_1 + v_2j \theta_2$.

This is a linear regression problem.

Solution is

$$\begin{aligned} & (\bm I_2 + \sum^2_i\phi(s_i, a)\phi(s_i, a)^\top )= \bm I_2 + \phi(s_1, a)\phi(s_1, a) ^\top + \phi(s_2, a)\phi(s_i, a_j)^\top \\ =&\left(\bm I_2 + \begin{pmatrix} v_{1,\ a} v_{1,\ a} & v_{1,\ a} v_{2,\ a} \\ v_{2,\ a}v_{1,\ a} & v_{2,\ a} v_{2,\ a}\end{pmatrix}\right)^{-1} \sum^2_{i=1} \phi(s_i, a) r_i \end{aligned}$$
