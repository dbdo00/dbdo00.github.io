#. Find all finite groups in which the number of classes of conjugate elements is equal to $2$.
Proof. This group is the group of order $2$. The size of the conjugacy class $C$ that is not the identity element divides the size of group, $n$, from which $n-1 \mid n$. Since $n-1$ and $n$ are coprime, we conclude that $n-1 \mid 1 = n - (n - 1)$ (Bezout's lemma). So $n-1=1$.
