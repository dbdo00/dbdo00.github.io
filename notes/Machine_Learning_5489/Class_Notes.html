后验分布

参数$\theta$ 的后验分布的密度是 $P(\theta |D)$。 这个是参数的分布

$$P(\theta |D ) = \frac{P(D \mid \theta) P(\theta)}{P(D)}$$

$P(D)$ 的定义是样本密度。类似于 Class Notes 中的“平均有多少个样本落在类别 c 中”。

后验预测 $P(x^\star \mid \theta )$

这只是给定参数$\theta$ 的$x$. （意思是 $P(X = x^\star \mid \theta)$ , $X$ 有一个参数是$\theta$. 的分布）

后验估计:

$$p(x^\star | D) = \int P(x^\star \mid \theta)P(\theta |D)d\theta$$

后验分布

Maximum a posterior

如果在$\theta=t$ 时，数据$D$ 有分布$p(D|\theta =t)$. 并且我们也假设知道$\theta$ 是什么分布。那么MAP 就是计算

$$\arg \max_\theta p(\theta = t|D=x) = \arg \max_\theta \frac{p(D=x \mid \theta =t)p(\theta =t)}{\displaystyle\sum_s p(D=x|\theta=s)}$$

[修改] 实际上 分母和$\theta$ 没关系，所以只要最大化分子就可以

$$\arg \max_\theta p(\theta = t|D=x) = \arg \max_\theta p(D=x \mid \theta =t)p(\theta =t)$$

ML是反过来P 中 的 $\theta$ 和$D$

K-means

$\pi_k$ 观察到第k堆的概率。这是一个隐变量 $Z= k$ 的概率。

观察到向量$x_i$ 的条件下，在第$k$ 堆的概率：

$$\gamma_{ik} = P(Z= k\mid x_i )$$

因为一个空间所有样本概率总和为$1$, 所以
$$\sum_k \gamma_{ik} = 1. \tag{1}$$

K means - Soft Assignment

$Z = k \mid x_i$ 不是一个常数(即，不在任意一点概率是1)。

$Z \sim N(\mu_k^{(0)}, \sigma_k^{(0)})$ 时
E-M step 可以更新$\mu_k$ 和$\sigma_k$. 分别有一个公式……

Hard Assignment

$\gamma_{ik} \in \{0,\ 1\}$ 。更新后的中心是一堆中所有点的平均

$$\mu_{k}^{(1)}=\frac{\sum \gamma_{ik} x_i}{\sum_i\gamma_{ik}} =\frac{\sum_{i在第k堆中} x_i}{\sum_{i 在第k堆中} 1}$$

MLE 和 MAP 区别

1. 极大似然估计（MLE）

  • 不需要先验（No Prior）。
  • 基本逻辑：只关注当前观察到的数据 $x$。它假设参数 $\theta$ 是一个固定但未知的真实常数，寻找能使数据 $x$ 出现概率（似然 $p(x \mid \theta)$）最大的那个 $\theta$。
  • 数学表示：
    $$\hat{\theta}_{\text{MLE}} = \arg\max_{\theta} p(x \mid \theta)$$

2. 后验估计（例如 最大后验估计 MAP）

  • 必须需要先验（Requires Prior）。
  • 基本逻辑：基于贝叶斯学派的观点，参数 $\theta$ 本身也是一个随机变量，在观察到数据之前我们就对它有一定的认知或倾向（先验分布 $p(\theta)$）。后验估计通过贝叶斯公式将“先验”与“数据似然”结合，寻找使后验概率 $p(\theta \mid x)$ 最大的 $\theta$。
  • 数学表示：
    $$\hat{\theta}_{\text{MAP}} = \arg\max_{\theta} p(\theta \mid x) = \arg\max_{\theta} \left[ \underbrace{p(x \mid \theta)}_{\text{似然}} \cdot \underbrace{p(\theta)}_{\text{先验}} \right]$$

总结对比

  • MLE = 纯粹看数据（$\text{数据似然}$）
  • 后验估计（MAP） = 数据 + 经验（$\text{数据似然} \times \text{先验概率}$）
    当先验分布 $p(\theta)$ 是均匀分布（即对所有可能的 $\theta$ 不偏不倚，等概率看待）时，MAP 的计算结果就会退化为与 MLE 完全一致。
