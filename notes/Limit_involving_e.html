Limit involving e

last updated: Nov 20, 2025

  • Basics

    $\lim_{n\to \infty} (1+1/n)^{1/n} = e$

    Estimate $1 + ½ + 1/3! + \ldots + 1/n!$

  • Upper Bound

    If $a_1, a_2 \ldots$ are positive real numbers, prove

    $$\limsup_{n\to \infty} \left(\frac{1 + a_{n+1}}{a_n}\right)^n \geq e$$

    这个序列中，比小于 $\sqrt[n]{e}$ 不可能永远持续下去。
    总是可以找到 subsequence 使得极限等于某个大于等于 $e$ 的数。
    对这种抽象的序列，我们唯一知道它样子的办法是对它做迭代。
    怎么找到合适的迭代方式？

  • Product

    For a limit of products, it is natural to take logarithm and estimate the summation.

    $$\lim_{n\to \infty} \frac{(1\cdot 2^2 \cdot \ldots \cdot n^n)^{\frac{1}{n^2}}}{n^{1/2}} = e^{\frac{1}{4}}$$

    We estimate the upper bound of $\frac{1}{n^2} \sum^n_{k=2} k\ln (k)$ .

    Notice that $f(x)=x\ln x$ is monotone increasing.

    Upper bound:

    $$\sum^n_{k=2} k \ln k \leq \int^{n+1}_{2} x \ln x dx \leq \int^{n+1}_{1} x \ln x dx$$
    Lower bound:
    $$\int^{n}_{1} x \ln x dx \leq \sum^{n}_{k=2} k \ln k$$

    The difference of upper bound and the lower bound is $O(n\ln n)$.
    The error is bounded by
    $$\rm upper\ bounded - lower\ bound$$

    Visually, the error is bounded above by the tail: the area below the curve of the function $f(x)$ on $[n,n+1]$; this area is at most $f(n+1)$.

    That is,

    $$\sum^n_{k=2} k \ln k = \int^{n+1} _1 x \ln x + O\left(\int^{n+1}_n x\ln x \right)dx =\int^{n} _1 x \ln x + O\left(n\ln(n)\right)$$

    because
    $$\int^{n+1}_nx\ln(x)dx \leq (n+1) \ln(n+1) = O(n)(\ln(n) + \ln(\frac{n+1}{n}))= O(n)O(\ln n) = O(n\ln n)$$
    as $n\to \infty$, from which it follows that (1) equals
    $$\frac{1}{n^2}\left(\frac{1}{2}n^2 \ln n - \frac{1}{4} n^2 + O(n\ln n)\right)$$
    .
    So the logarithm of the original function is
    $$\frac{1}{2}\ln n - \frac{1}{4} + O\left(\frac{\ln n}{n^2}\right) - \frac{1}{2}\ln n \to \frac{1}{4}$$

    and so the limit is $\exp(1/4)$.

    A stronger(?) tool for handling summations is Euler-Maclaurin Expansion.
