  • Recall that for all positive $\epsilon$, $x^\epsilon$ is $o(\ln(x))$ as $x\to 0$.
    • that is, $\lim_{x\to 0}x^\epsilon\ln (x)$.
    • So, $\lim_{x\to 0} \frac{x\ln(x)}{x^{1-\epsilon}} =\lim_{x\to 0} x^\epsilon \ln (x) = 0$.
    • More roughly, we can say that $x\ln(x) = O(x^{1-\epsilon})$ for $|x| <\delta$.
    • Notice that when $\epsilon >1$, everything above is still valid. (Why?)
    • And it is not correct to say $\color{red}x\ln(x) =O(x) (\quad \rm incorrect)$

  • This helps to find the number of centralizer (the elements that commute with a group elment $x$). The orbit of the action on $x$ is the conjugacy class and the stablizer is the centralizer. The conjugacy class of $x\in S_n$ is easy to find. So the stablizer (e.g. centralizer) is easy to find.
