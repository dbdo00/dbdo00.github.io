#. $$\int_{x^2 +y^2 \leq 1} |3x + 4y|dxdy$$
Solution.
Let $\varphi=\arctan(3/4)$. Then $$\sin(\theta + \varphi)=\sin(\theta)\cos(\varphi) + \cos(\theta)\sin(\varphi)=\frac{1}{5}\bigg( 4 \sin(\theta) + 3 \cos(\theta)\bigg).$$

  • Use the polar coordinate $x=r\cos(\theta), y=r\sin(\theta)$. Let $u=\theta + \varphi$.

  • $$\begin{align*}
    & \int^1_0 \int^{2\pi}_0 |3 r cos(\theta) + 4 r \sin(\theta)| {\color{blue} r}d\theta dr \
    = &\int^1_0 \int^{2\pi}_0 5r^2 |\sin(\theta + \varphi)|d\theta dr\
    = &\frac{5}{3}\int^{2\pi}_0{\color{red}|\sin(u)|}du \
    = & \frac{20}{3}
    \end{align*}
    $$
    Comments:

    1. $\int^{a+T}_{a} f(t)dt = \int^T_0 f(t)dt$ for a periodic function having period $T$ because $\int^{a}_0 f= \int^{a+T}_Tf$ .
    2. Let $u=\theta + \varphi$. Then $$\int^{2\pi}0 |f(\theta + \varphi)|d\theta = \int^{2\pi + \varphi}\varphi |f(u)|du=\int^{2\pi }_0 |f(u)|du$$ by the last comment.

    #. $$\lim_{n\to \infty} n^2 \int^{1/n}0 x^{x+1}dx$$
    Solution. By l'hospital's rule, $$\lim    {x\to 0+} x^{\epsilon}\ln x =0$$ for all $\epsilon >0$. So $\ln x = o(x^{-\epsilon})$ when $x\to 0+$. Taylor expansion gives
    $$x^x = \exp(x\ln x) = 1 + x\ln x + O(x\ln x) = 1 + o(x^{1-\epsilon}) + o(x^{1-\epsilon}) =1 + o(x^{1-\epsilon}) $$ Note $\int^{1/n}_0 o(x^{2-\epsilon})dx \leq o(1)\int^{1/n}_0 x^{2-\epsilon}dx =o(1)\frac{1}{3 - \epsilon}1/n^{3-\epsilon}$. Choose $0< \epsilon < 2$. Then $$\int^{\frac{1}{n}}_0 x^{x+1} dx =\int^{\frac{1}{n}}0 x + o(1/n^{2-\epsilon}) dx = \frac{1}{n^2} + o(\frac{1}{n^{3-\epsilon}})$$
    So $$\lim    {n\to \infty} n \int^{1/n}0 x^{x+1}dx = \lim{n\to \infty} 1 + o(\frac{1}{n^{1-\epsilon}}) = 1$$.
    Comment: The $+1$ here in the exponent has the effect of making the function goes faster to 0 at $0$.

  • If it is $+2$, then you would get smaller values (something like $\frac{C}{n^3} + \ldots$).

  • The $n^2$ in the question can be change $n^{2-\epsilon}$ for all $\epsilon >0$.
