Estimation of Summations

$\frac{1}{n} \sum^n_{k=1} n^{1/k}$

By plotting, you can find that the $\frac{1}{n} \sum^\infty_{k=1} k^{1/k}$ finally goes to $1$, because $\{k^{1/k}\} \to 1$, from which the average goes to $1$ by Cesaro-Stolz lemma.
Now replacing this sum by $\frac{1}{n} \sum^\infty_{k=1} n^{1/k}$, it helps to
estimate the new summation by splitting the sum into two pieces.

The summation is

$$n + n^{1/2} + n^{1/3} + \ldots n^{1/n}.$$

The first $\ln(n)$ terms can be estimated by summing $\sqrt n$.

Why would the upper bound $n^{1/k} \leq \sqrt n$ for the first $\ln(n)$ work?? The reason is that we know the sum
$\sum_{2 \leq k < \ln n} n^{1/k} \leq \ln(n) \sqrt n = o(n)$ as $n\to\infty$, and so this upper bound is sufficient.

Now we estimate $\sum_{\ln n \leq k \leq n} n^{1/k}$.

Inequality

The first inequality to use is

$$e^{\ln n /k} \leq 3\frac{\ln n}{k} + 1$$
for $k\geq \ln n$. ($e^x < 3 \implies e^x < 3x +1$ for $x\in [0,1]$)

Also, for $k \geq 2$,

$$1/k = \int^{k}_{k-1} \frac{1}{k} dt <\int^{k}_{k-1} \frac{1}{t} dt$$

So

$$\sum^n_{k=2} 1/k < \sum^n_{k=2} \int^k_{k-1} \frac{1}{t}dt = \int^n_{1} \frac{1}{t}dt =\ln n \tag{1}$$

Concluding Estimate

$$\sum_{\ln n < k \leq n} n^{1/k} = \sum_{\ln n < k \leq n} e^{\ln n/k} < 3 \ln n \left(\sum^n_{k=2} \frac{1}{k}\right) + n< 3\ln n \ln n + n = o(n) + n$$

Here we used the fact that $\ln^j(n) = o(n^k)$ for all positive $j,k$.

Comments

A key step in the estimation above is $e^x < 3x +1$ for $x\in [0,1]$, which is actually a quite precise one.
Generally, if $f(x)$ is convex on $[a, \infty)$, then $f(x)< Kx + D$ for $x\in (a,\infty)$, where $K=\frac{f(b)-f(a)}{b-a}$ and $D=f(a)-Ka$. As a result,

$$\sum_{a\leq x \leq n} f(x) = \underbrace{K\sum_{a\leq x \leq n} x}_{(1)} + \underbrace{Dn}_{(2)}$$
Note that when $a>1$, (1) is $O(n^2)$ while $(2)$ is $O(n)$. They are not able to become a constant by letting be divided by a power of $n$. However, when $x\in (0,1)$ and $a\leq 0$, we can possibly make (1) of the magnitude $o(n)$.

3.

$$\lim_{n\to \infty} \frac{1}{n}\sum^n_{k=1} \exp\bigg(\frac{\ln\ln n}{k}\bigg)$$

Solution. $\exp(\frac{\ln\ln n}{k}) = (\ln n)^{1/k}$. So $\sum \exp\bigg(\frac{\ln\ln n}{k}\bigg) = \sum (\ln n)^{1/k}$
The first piece of sum is $\sum_{1\leq k \leq \ln \ln n} (\ln n)^{1/k} \leq \ln\ln n (\ln n) = o(n)$
Note that for $x\in(0,1)$, $1\leq e^x \leq 1+ 2x$.
The second piece of the sum is
$$\sum_{\ln\ln n < k \leq n} (\ln n)^{1/k} \approx\sum_{\ln\ln n < k \leq n} \left( 1 + \ln\ln n (\frac{1}{k})\right)\leq n + \ln\ln n\bigg(\sum^n_{k=1} \frac{1}{k}\bigg)= n + \ln\ln (n) (\ln n)=n + o(n)$$
So the whole sum is $n+ o(n)$. Q.E.D.
Comment This proof splits the sum when $x$ in $e^x$ is greater than 1 than when it is less than 1. So, the key there is still the inequality $1\leq e^x \leq 1 +2x$. It is evident that, to make this average approach $1$ when $n\to \infty$, the choice of function $f(x)$ in the expression $f(x))^{1/k}$ is unessential.
