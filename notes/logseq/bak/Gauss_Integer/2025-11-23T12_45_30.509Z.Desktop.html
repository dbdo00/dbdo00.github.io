  • If the norm of a Gauss integer is the square $p^2$ of a prime number such that $p \equiv 3\pmod 4$, then this integer prime $p$ is a Gauss prime.

    Proof. If it is not a Gauss prime, then it can be written as $p=\alpha\beta$, where $\alpha,\ \beta$ are non-units in the Gauss integers. So

    $$p^2=N(p)=N(\alpha)N(\beta)$$

    Since $\alpha$ and $\beta$ are non-units, $N(\alpha)=p$ and so is $N(\beta)$.
    Let $\alpha = a + bi$ ($a,b$ are ordinary integers). Then $p = a^2 +b^2 \equiv 1 \pmod 4$, which contradicts the assumption that $p\equiv 3 \pmod 4$. $\square$

  • Description of Irreducible Elements

  • If $\pi$ is a Gauss prime, then we can show that $N(\pi)$ is either an integer prime or the square of an integer prime.

    Proof. If $N(\pi) = p_1p_2$ for some integer primes $p_1,p_2$, then $p_1$ is either an associate of $\pi$ or $\bar \pi$. Suppose it is $\pi$, so that $p_1 = u\pi$ from which $p_2 = u^{-1}\pi$, where $u=\pm i, \pm 1$.
    If $u=1$, then $u^{-1}=1$. If $u=\pm i$ or $-1$, then $u^{-1}=-u$. So, $N(\pi)=N(\pm p_1^2)=p_1^2$.
    (By the way, we have shown that $p_1$ ($=p_2$) is a Gauss prime, too.)

  • In other words, if the norm $N(a)$ is not one of these types, the number $a$ is not a Gauss prime.

  • Suppose $N(\pi)$ is $p$ or $p^2$ ($p$ is an integer prime). If $N(\pi)=p$, then $\pi$ is a Gauss prime. Otherwise, if $N(\pi)=p^2$, then we consider $p\pmod 4$.

    • if $p \equiv 1 \pmod 4$ (so $p=q \bar q$ for some Gauss prime $q$), then $\pi$ is not irreducible because if it is, then $p^2 = q^2\bar q^2$, from which we get know $p^2$ is not a product of $2$ prime factors, and instead $4$ prime factors in Gauss integers. So $\pi$ can not be a prime.
    • if $p \equiv 3 \pmod 4$, then $\pi$ is a prime.
