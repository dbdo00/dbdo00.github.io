  1. Is
    $$\frac{1}{1 + z^n}$$
    convergent or divergent for complex number $z$?

Hints. Comparison test for positive series: Suppose $\{a_n\}$ and $\{b_n\}$ are positive series. If $\lim_{n\to \infty} \frac{a_n}{b_n} = A (\neq 0)$, then $\sum a_n$ and $\sum b_n$ simutaneously convergent or divergent.
Term Test: If $\sum a_n$ is convergent, then $\lim_{n\to \infty}a_n =0$.

Solution. If $|z|<1$, then $\lim_{n\to \infty} \frac{1}{1 + z^n} = 1 \neq 0$. So the series $\sum \frac{1}{1 + z^n}$ diverge. If $|z|=1$, then

$$\left|\frac{1}{1 + z^n}\right| \geq \frac{1}{|1| + |z^n|} = \frac{1}{1 + 1} = \frac{1}{2}.$$
from which $\sum \frac{1}{1 + z^n}$ diverge when $|z| = 1$. If $|z| >1$, then $\lim_{n\to \infty} \frac{1}{1 + \frac{1}{z^n}} = 1$. Let $b_n = \frac{1}{z^n}$. The series $\sum \frac{1}{1 + z^n}$ converges because
$$\lim \bigg(\frac{1}{1 + z^n}\bigg) \bigg/b_n = \lim_{n\to \infty} \frac{1}{1 + \frac{1}{z^n}} = 1$$
from which the comparison test confirms the convergence. $\square$
