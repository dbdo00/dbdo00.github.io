linux 打印机 cups 配置



2026-03-30 foomatic db 数据库需要安装，否则可能驱动缺失。

自带程序自动检测驱动可能错误。需要提前知道对应的驱动。比如联想打印机是brother2040驱动。

点击勾选：network printing。允许内网设备打印。

此外要装avahi, 使得其他设备能识别出来

add 是新加上的， 网络好像必须add 才能共享。find 是已经存在的，

选择shared 才能局域网中探索到。网页端出现不能设置为shared 的情况： 解决是修改/etc/cups/printers.conf 中Shared 选项 如果网页上选择modify, 配置文本会被重写。

强行允许网页和远程访问：

sudo cupsctl --remote-admin --remote-any --share-printers

这很有用。因为如果你在管理网页上误点了change settings，会按照网页上的设置， 重写配置文件。如果网页上的设置恰好没有允许局域网其他设备访问，其他设备就不再能访问。上面的命令能做到允许访问。
