Symbolic link

Symbolic link links a file to another file. For example, if you enter ln -s a b, and then you enter b, you will execute the file a.

Actually, if you omit -s, then ln will check if the target a exists. But by using -s, upon user entering b, your ln program will resolve to a.

How is the resolving done?

    Symbolic links can hold arbitrary text; if later resolved, a relative link is interpreted in  relation to its parent directory.

Try type the following

mkdir foo
echo "eepy.." > foo/bar.txt
ln -s foo/bar.txt foo/bar

and what would happen after you enter cat foo/bar?
