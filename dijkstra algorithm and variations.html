dijkstra algorithm and variations



2026-11-02 A version of dijkstra implementation online returned in the first place in the google search result is good. But it does not returns the nodes visited along the path.

The way to use path is pretty simple: record the parents.

import heapq
import sys

def dijkstra(adj, src):

    V = len(adj)

    # Min-heap (priority queue) storing pairs of (distance, node)
    pq = []
    parent = [-1] * V

    dist = [sys.maxsize] * V
    path = [src]
    # Distance from source to itself is 0
    dist[src] = 0
    heapq.heappush(pq, (0, src))

    count = 0
    # Process the queue until all reachable vertices are finalized
    while pq:
        count +=1 
        print(f'{count}-th iteration')

        d, u = heapq.heappop(pq)
        print(d,u,"is poped from the queue")

        # If this distance not the latest shortest one, skip it
        if d > dist[u]:
            continue

        print(f'd={d}, u={u}, dist[u]={dist[u]}')
        # Explore all neighbors of the current vertex
        for v, w in adj[u]:

            # If we found a shorter path to v through u, update it
            if dist[u] + w < dist[v]:
                print(f"new distance {dist[u] + w} to {v} via {u} is shorter than the old distance {dist[v]}")
                dist[v] = dist[u] + w
                heapq.heappush(pq, (dist[v], v))
                parent[v] = u
                print(f"now pq={pq}")

    # Return the final shortest distances from the source
    return dist, parent

Is this really Dijkstra?

After studying this code, i found something strange.

  1. it doesn’t have a CLOSED array for the examined nodes. But the Dijkstra is supposed to have such an array.
  2. More surprisingly, this program actually supports directed acyclic graph with edges (or arcs, if you prefer!) of negative weights , even though what we learned is “dijkstra algorithm does not support negative weight.

This made me curious how dijkstra algorithm can be modified and extended.
